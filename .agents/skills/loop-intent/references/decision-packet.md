# Prepared decision

State the current goal, the exact unresolved choice, evidence and counterevidence, the recommended route, alternatives and their consequences. Explain which work is blocked and which can continue. Record the user's actual answer and the approved artifact digest. Do not invent consent, quote a user who did not speak, or turn a technical investigation into a business-value question.

Question budget is based on changed decisions, not document completeness. Do not ask again when the answer is already present and still valid.
