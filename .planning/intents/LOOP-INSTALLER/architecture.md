# Architecture
No scheduler. Node bin launches Python >=3.11. Package whitelist excludes project state, CI identity and test evidence. Framework scripts live under .loop/core/scripts; canonical Loop skills remain .agents/skills with relocated command references. Project configuration is create-only, not framework-owned. A per-file manifest controls upgrade/removal. Existing rule semantics are not silently merged. Official upstream installers run in staging, only recognized outputs are planned into the target; conflicts refuse without overwrite. Native config conflicts are review-required, not a force flag. A guarded write journal records before/after content and modes; recover rolls back only files still matching either image. npm caches and upstream subprocess side effects outside the project are outside the file rollback guarantee.
