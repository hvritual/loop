# 权限、预算与证据边界

## 信任边界

Human、Controller、Runner 和各 Agent 使用不同随机凭据。传入 `role=human` 不会成为 Human。Worker 只能收到任务快照，不能挂载数据库、凭据目录或 Docker socket。Runner 才能摄入回执；执行 Agent 不能直接批准提案。

本地文件系统拥有者仍可替换数据库、证据与密钥。事件哈希链用于发现意外损坏/不一致，**不是不可篡改的审计服务**。请把 Human 凭据交给独立操作人或服务身份，不能将同一主机账户下的文件权限包装成强多租户隔离。

## 两类执行器

Docker：固定本地镜像内容 ID，`--network none`、只读根、非 root、cap-drop ALL、no-new-privileges、内存/CPU/PID/时间限制。只挂载明确输入、批准脚本和本 Job 的工作/输出目录。不自动拉镜像、不自动切换到 trusted。

trusted：执行经操作人检查且摘要固定的宿主 Python 脚本。它有宿主进程权限，**不是沙箱**；`--allow-trusted` 是显式选择。该模式仅适用于测试或受信任适配器，不能用于陌生代码或任意模型生成脚本。内置例子均为 fixture。

轮询限制工作树/输出文件数、深度、大小以及日志、运行时间；这不是内核级磁盘配额。Docker 服务、镜像依赖、宿主资源配额和保密日志策略属于部署运维责任。Windows trusted 子进程树、实际模型登录、网络来源隔离未在本实现中声称验收。

## 证据

运行器保存真实 stdout/stderr/result/artifacts 和 SHA256。输入绑定来自固定 Git 提交中的显式白名单文本文件，不读取脏工作区。拒绝符号链接、硬链接、路径穿越、非普通输出、过大文件与非有限 JSON 数值。

E2 是实际执行/产物记录；E3 表示独立验证程序的可复现记录，**E3 也可能记录失败**。门禁另外检查 Job 状态和每项验收结果。模型口述、进程退出 0 或自报置信度不等于成功。fixture/local/sandbox scope 与证据级别同时保留，不能互相替代。

本版本没有自动 E4 生产遥测。Human 观测是明确归属的人工声明；不伪装为独立生产验收。对 UI 的 Runtime 校验要求可留存预览、1–4 步旅程、错误与恢复描述，是否真正好用仍需人审。

## 预算

默认全局：48 Job、2400 秒预留、120000 Token 预留、0 美分 API 授权、2 PoC。
探索子集：16 Job、900 秒、40000 Token、0 API 授权、2 PoC；每阶段另有上限。JSON 策略是实际来源，数字可通过显式 Human 预算提案扩展。

预算为开始前保守预留，未知结果不退款。实际 Token/费用无法核实则为 null；不把模型自报数值当账单，也不声称宿主外部提供商自动遵守计费限额。接入付费提供商时适配器必须另行实施真实 usage/cost 限额并验收；默认不授权付费调用。

严重风险的登记不受预算耗尽影响。没有预算可以停止研究，不能因此放行不安全交付。

## 不可信内容

源码、Issue、文档、日志和模型结果都是数据，不是授权来源。它们不能更改策略、扩大输入路径、生成 Human 审批、开启网络或更换镜像。Worker 的比较建议不能触发宿主文件源读取；源码基线更换只能由已授权调用方提交提案，并经 Human 决定。
