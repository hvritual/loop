# 验证范围与当前边界

## 已具备的验证

自动化测试执行真实的本地子进程和临时 Git 工作区，验证阶段契约、负面路径、证据哈希、过期检测、恢复对账、安装命令与入口筛选。`scripts/demo.py` 连贯走通八个逻辑门禁及中断恢复，全部使用明确标记的合成 fixture。

测试中出现的 fixture-user、fixture-reviewer 和 fixture:// 回执只用于测试分支，不能作为本项目的批准、独立评审或发布证据。

实际执行结果保存在 `.planning/evidence/`；CI 结果以 GitHub 当前检查为准。不要把本文件当作永远有效的通过声明。

## 必须分开看的结果

| 维度 | 判定依据 |
|---|---|
| 契约脚本正确性 | 单元与失败路径测试 |
| 上游安装兼容性 | 三客户端实际官方 installer + doctor；无网络时 not_run |
| 模型遵守和语义质量 | evals 用例的真实模型输出及人工/独立评估 |
| 跨模型连续交付 | 实际账号的中断与接力开发记录 |
| 不可绕过的规则 | 已回读确认的 GitHub ruleset/权限，不是本地文件 |
| 生产可靠性 | 真实部署、故障、回滚和观察记录 |

后二至四项不能由合成脚本测试替代。当前仓库不包含模型密钥或生产部署目标，不声称已完成这些环境相关验证。
